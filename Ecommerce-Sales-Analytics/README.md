# E-Commerce Sales Analytics

## 📌 Project Overview

This project analyzes e-commerce sales data to understand revenue
performance, product performance, customer purchasing behavior,
payment methods, and monthly sales trends.

The project uses Python, Pandas, NumPy, Matplotlib, MySQL, and SQL.

## 🎯 Objectives

- Analyze total sales and revenue
- Identify top-performing products
- Analyze revenue by category
- Identify high-value customers
- Analyze monthly revenue trends
- Analyze payment methods
- Identify repeat customers
- Perform customer segmentation

## 📊 Dataset

The project contains:

- 200 customers
- 50 products
- 1,000 orders
- 1,962 items sold
- ₹68,91,926 total revenue

## 🧹 Data Cleaning

The data was checked for:

- Missing values
- Duplicate records
- Invalid quantities
- Invalid prices
- Invalid customer IDs
- Invalid product IDs

Date columns were converted from strings to datetime format.

A revenue column was created using:

`Revenue = Quantity × Price`
